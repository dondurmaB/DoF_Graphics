# Experiment 03 — Uniforms and Animation

## Purpose

Learn how uniforms send shared CPU-side runtime values into shaders, and use elapsed time to animate brightness and horizontal position.

## Main Concepts

- uniforms
- vertex attributes vs uniforms
- uniform locations
- `glUniform1f()`
- `glfwGetTime()`
- sine-based animation
