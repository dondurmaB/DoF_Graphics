# Experiment 04 — Transformation Matrices

## Purpose

Learn how fixed model-space geometry is translated, rotated, and scaled with a 4x4 transformation matrix sent to the vertex shader.

## Main Concepts

- `glm::mat4`
- identity matrix
- translation
- rotation
- scaling
- homogeneous coordinates
- transformation order
- `glUniformMatrix4fv()`
