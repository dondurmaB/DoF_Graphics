# Experiment 06 — Depth Testing and the Depth Buffer

## Purpose

Enable OpenGL depth testing and render two overlapping cube instances from the same indexed mesh. This shows how the depth buffer makes 3D visibility independent of draw order.

## Run

From the repository root:

```bash
cmake -S . -B build -G Ninja
cmake --build build
./build/DepthResearch
```
