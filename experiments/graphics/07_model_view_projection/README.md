# Experiment 07 — Model, View, and Projection

## Purpose

Separate cube transforms into model, view, and projection matrices. This shows the complete basic path from local cube vertices through a static camera and perspective projection.

## Run

From the repository root:

```bash
cmake -S . -B build -G Ninja
cmake --build build
./build/DepthResearch
```
