# Experiment 01 — Vertex Attributes and Interpolation

## Purpose

Preserve the source snapshot for the vertex attribute layout and interpolation experiment. This experiment stores position and color per vertex, then lets the rasterizer interpolate color across the triangle.

## Main Concepts

- VBO memory layout
- VAO configuration
- vertex attributes
- stride
- offsets
- interpolation
- primitive assembly
